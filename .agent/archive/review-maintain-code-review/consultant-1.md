M2: `Cli.stamp` reads `Std.Time.PlainDateTime.now` directly (`Fvtrace/Cli.lean:166–171`). The live probe uses installed `faketime` with `TZ=UTC` + frozen `2000-01-02 10:10:10`; `pin --replay` returns 0 + the log stores exactly `2000-01-02T10:10:10`.
