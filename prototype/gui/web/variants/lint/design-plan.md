# Manuscript proof

## Palette
- Paper `#ffffff` = manuscript + notes.
- Desk `#e9edf2` = outer workspace.
- Ink `#25324a` = prose + controls.
- Pencil `#a3273d` = overstatement + correction marks.
- Query `#765500` = unstated premise + hypothetical view.
- Approved `#23614b` = supported text.

## Type
- Georgia = manuscript sentences, 23px / 1.65 desktop; 21px mobile. Width ≤ 48ch.
- System sans = navigation, referee notes, controls; 14/16/18px hierarchy; headline 40px. Note width ≤ 58ch.
- Bold element = opening title. Other hierarchy = space, indentation, proof marks.

## Layout
```
fvTrace                 Manuscript check           All variants

Prototype disclosure

┌ manuscript page ───────────────────────────────────────┐
│ Results draft                 Referee notes             │
│ sentence + pencil bracket     verdict, asserted claim   │
│                               reason + suggested edit   │
│                               [Accept rewrite]          │
│                               ▸ What would make…        │
│ sentence                      note…                     │
└────────────────────────────────────────────────────────┘
```
Mobile: one column; each note immediately follows its sentence. Document has no card grid or decorative dividers. Sticky hypothetical notice keeps invented premises visible.

## Domain principles
- The prose is the working surface. Proof marks attach to sentences; notes explain their evidential burden.
- Verdicts belong to original sentences. Accepted stub rewrites are visibly local edits, never silently certified.
- Each obligation exposes evidence, verification route + trusted base. A hypothetical proof is explicitly a supposition, not a new result.
- White manuscript + cool gray desk + red pencil avoids nostalgic cream/serif/terracotta styling. Serif is confined to actual manuscript prose.
- No external assets, gradients, shadows, ornament, entrance motion or hover motion. Native disclosures + underlined links remain familiar.

## Brief test
A ledger would foreground claim rows; this surface instead foregrounds editable Results prose. A graph would foreground dependencies; these appear only in sentence-bound referee notes. Copy-editing marks + local acceptance distinguish this variant from a generic dashboard.
