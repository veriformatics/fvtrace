# Claim ledger

## Palette
- Notebook white `#ffffff` = assertion surface.
- Graph-paper blue `#edf3f8` = desk + ruled writing field.
- Carbon navy `#20364b` = text + primary controls.
- Verification green `#236247` = verified claims.
- Premise violet `#654984` = conditional claims.
- Correction red `#a13539` = contradicted claims; open uses carbon navy.

## Type
System sans (Arial/Helvetica) throughout; 36px title, 24px question,
18px claim, 16px body, 13px references. Reading measure = 68ch.
Bold weight reserved for titles, state totals, and key actions.

## Layout
```text
fvTrace / Claim ledger                         Private study
Study title + scope                              Prototype
[ can 1 ][ conditional 1 ][ open 7 ][ cannot 4 ]
[ question 1 ][ question 2 ][ question 3 ][ question 4 ]
Scientific question                | Verification worth doing
[ state heading ]                  | Ranked fact + unlock count
  Claim assertion                  | Route + evidence
  gaps + evidence + verify route   | [Suppose verified]
[ next state heading ]             | More work ...
[ directions that open if ... ]     |
Draft wording / disclosure         |
```
Mobile = same reading order; totals 2×2; question selector vertical;
verification work follows assertions. No sticky obstruction on mobile.

## Domain principles
- An accounting of assertions, not a performance dashboard: totals are balances,
  questions are ledger tabs, facts are supporting entries beneath each claim.
- Wide square-ended status marks + explicit symbols distinguish account states.
- Evidence stays adjacent to the claim it qualifies; route text explains the next
  action without requiring formal-method vocabulary.
- What-if is a pencil entry: an explicit blue notice + changed-claim list, never
  a silent replacement for the actual account.
- Latent directions stay separate from assertions already under consideration.

## Brief test
Cool white + blue rather than cream/serif; no shadows, gradients, rounded-card
collection, eyebrow tracking, or decorative numbering. The bold element is the
four-cell assertion balance. The ledger uses generous row separators rather than
broadsheet hairlines. System type and no animation keep reading quiet. State is
encoded redundantly by text, symbol, and hue. Evidence may be expanded, but gaps
and their routes remain directly visible.
