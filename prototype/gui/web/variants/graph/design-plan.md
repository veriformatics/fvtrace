# Claim circuits

## Palette + type
- Paper #F3F6FA; panel #FFFFFF; ink #23354A; conductor #506984; verified #16634B; assumption #795400. Broken uses ink + a break shape; open uses conductor + an open contact. Status always = shape + words.
- System sans (`Segoe UI`, Arial): body 16/24; claim 18/26; question 24/31; title 40/44; reference 12/18. Text column ≤ 70 characters. No downloaded fonts.

## Layout
```text
fvTrace / Claim circuits                  Prototype / study context
Follow the evidence, close the circuit.   [lit] [assumption] [open] [broken]
[Question 1] [Question 2] [Question 3] [Question 4]
[question text                                            ]
[claim lamp + full text                ][selected fact / claim]
[wire — switch — switch — switch — lamp][evidence              ]
[claim lamp + full text                ][verification route    ]
[wire — switch — ...                   ][suppose verified      ]
[latent dashed claim + circuit        ][trusted base           ]
[Switches that light the most lamps: ranked fact text + counts]
```
Mobile = question select → inspector → stacked claim circuits → work list; contact rails wrap into usable rows, never a miniature graph.

## Identity + interaction
- Scientific reasoning as a series circuit: every necessary fact must close, not a vague graph of related concepts. A broken contact blocks even when all others close.
- Claim lamp = one large visual element; evidence + proof routes stay quiet, readable, inspectable. Dashed enclosure denotes an overlooked direction, not an unsupported proof.
- Switch click = temporary supposition; adjacent fact reference = inspect. Persistent banner + reset distinguish hypothetical closure from evidence. Hash shares the scenario without saving it.
- Claims remain complete English sentences. Short contact labels describe obligation kind; inspector gives exact fact + source evidence.
- Ranking uses engine work order; count explicitly includes conditional claims, so a supplied assumption is never mislabelled a proof.

## Brief test
Generic dashboard cards replaced by serial wires, switch contacts + lamps tied to the actual dependency semantics. No chart library, gradients, entrance motion, decorative data labels, or generic accent headline. Horizontal question navigation expresses four real scientific questions. Mobile keeps readable text + actual controls rather than scaled SVG. Prototype source + stub rewrite limits remain visible.
