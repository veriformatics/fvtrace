# Server (`fvtrace serve`)

- Routes = the embedded GUI files (`FvtraceWeb.files`, byte-equal to `web/`, every `web/*.{html,js,css}` listed — `Tests/Assets.lean`) + `POST /api/answer` (body = a V-request `{whatif, action?, details?}`, ≤ `Server.bodyCap` = 16 MiB + 1 KiB, else 413, read only after access passes; answer = the envelope, the details or a problem, byte-equal to `fvtrace eval`'s, header `X-Fvtrace-View` = the view the answer read (`Session.viewOf`: trace member + bindings + what-if); a request naming another view = 409 `view`). No route serves project files: evidence reaches the GUI as receipts inside the envelope; a file-reading route would turn a token leak into a project-folder leak (`fvtrace-trust` holds `Fvtrace.Server` to the `network` capability alone).
- Access, decided by the pure `Server.decide` before any I/O, in this order: the method (`POST` on `/api/answer`, `GET` elsewhere: 405); `Host` ∈ the allowed names (421: DNS rebinding) = loopback: `fvtrace.localhost`, `localhost`, `127.0.0.1`, `[::1]` + the port; `--host A`: `A` (or `[A]`) + the port; the GUI files answer without a credential (open-source code, no data); `/api/answer` needs `Authorization: Bearer <token>` (403 + `{problem: {kind: "access"}}` otherwise: no unauthenticated request reaches a body, `Overrides.parse` or the trace), compared with `sameSecret` (length + byte-xor fold, no early exit). No cookie, set or read: cookies ignore ports, so one would reach every server on the host (security review F2). No CORS header: a page from another origin cannot send `Authorization` (or a JSON body) without a preflight, and OPTIONS answers 405. `--host` takes one concrete address (a wildcard has no single `Host` name to allow).
- Bind (`Cli.serveCmd`): loopback = one port on both `127.0.0.1` and `[::1]`, since `localhost` names reach either (Chromium tries `::1` first): `[::1]` busy (`IO.Error.resourceBusy`) → refuse to serve on a fixed port (the message names `[::1]:<port>`), under `--port 0` shut the IPv4 listener + take another free port (bounded attempts); `[::1]` unsupported (`unsupportedOperation`: no IPv6) → IPv4 alone. Default port 8718 (U+220E ∎; the help leaves the easter egg unsaid).
- Link = `http://fvtrace.localhost:<port>/#token=<token>` (`--host`: the address): the `#` part never reaches a server, a log or a `Referer`. `serve` opens it itself unless `--no-browser`, `--host`, an SSH session (`SSH_CONNECTION` | `SSH_TTY`), WSL (`WSL_DISTRO_NAME`) or, on Linux, no display (`DISPLAY` + `WAYLAND_DISPLAY` unset): it writes a redirect page into `<data folder>/serve/` (folder set to mode 0700 on every run, before the write) and runs the platform opener (`xdg-open` | `open` | `explorer.exe`) with that file's path as its one argument — a link on a command line shows in every user's process list. Opened → prints the address, then the link as a fallback line: an opener's exit 0 does not prove the page loaded (a Snap browser cannot read hidden folders; macOS may hand HTML files to another app). Not opened or the opener failed → prints `Open <link>`.
- GUI (`web/app.js`, served mode): takes `token` from the address once, removes it before `readHash` or any `pushState` (`history.replaceState`, the other hash parameters kept, so no history entry keeps it), keeps it in `localStorage` (one origin = one port) once the server accepts it (any answer but 403: a 400 what-if problem counts, since access is decided first) (a refused address token leaves the stored one: another site may link `#token=junk`), sends it on every evaluation request.
- Every response carries `fixedHeaders`: CSP `default-src 'none'` + `'self'` scripts/styles/connect, `frame-ancestors 'none'`, `require-trusted-types-for 'script'; trusted-types 'none'` (HTML-string sinks throw), `nosniff`, `no-referrer`, COOP/CORP same-origin, `no-store`.
- The port (so the hosts) is known only after binding (`--port 0`), so `Server.Config` sits in an `IO.Ref` filled after `Server.start`; a request before that meets an empty host list.
- e2e (`tests/e2e/fvtrace-server.js`) runs the built binary: temp `FVTRACE_HOME` + project with the synthetic study pinned, `serve --port 0 --no-browser`, the printed link (tests append view parameters with `&`: the link ends in `#token=…`). `lean-build` must precede `e2e`.
